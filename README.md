# Cacheta Master 4.1

Aplicativo web instalável para marcar partidas de Cacheta.

## Estrutura

- index.html
- manifest.webmanifest
- service-worker.js
- README.md
- css/style.css
- js/app.js
- js/game.js
- js/storage.js
- assets/icon-192.png
- assets/icon-512.png

## Recursos

- Cadastro de 2 a 10 jogadores
- 10 pontos iniciais
- Desistiu: -1 ponto
- Perdeu: -2 pontos
- Eliminação automática em 0 pontos
- Jogador eliminado fica oculto da tela
- Modo rápido
- Modo rodada
- Desfazer
- Histórico
- Ranking
- Campeão automático
- Salvamento no aparelho
- Funcionamento offline
- Instalação como PWA
